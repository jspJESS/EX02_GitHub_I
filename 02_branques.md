# 2. Branques

**Responsable:** alumne/a 2 (Alex)

## Què és una branca?

**Resposta:** Una branca és una línia de treball independent dins d'un projecte. Permet fer canvis o afegir coses sense modificar directament el projecte principal (`main`). Es treballa en una branca pròpia perquè cada persona pugui fer la seva part sense afectar la feina dels altres.

## Ordres

- `git branch`:

  **Resposta:** Serveix per veure les branques que hi ha al projecte i també per crear-ne una de nova.

  Exemple: `git branch ex02-02-usuari`

- `git switch`:

  **Resposta:** Serveix per canviar-te a una branca que ja existeix.

  Exemple: `git switch ex02-02-usuari`

- `git switch -c`:

  **Resposta:** Serveix per crear una branca nova i canviar-hi directament.

  Exemple: `git switch -c ex02-02-usuari`

## Mini exemple

Escriu les ordres per crear una branca anomenada `ex02-02-usuari` i per canviar-te a una branca existent amb aquest nom.

**Resposta:**

Crear la branca i entrar-hi:

`git switch -c ex02-02-usuari`

Canviar a una branca que ja existeix:

`git switch ex02-02-usuari`

## Pregunta

Quina diferència hi ha entre crear una branca i canviar-te a una branca que ja existeix?

**Resposta:** Crear una branca significa fer una nova línia de treball dins del projecte. En canvi, canviar-te a una branca existent significa entrar en una branca que ja s'havia creat per continuar treballant-hi, sense crear-ne una de nova.
