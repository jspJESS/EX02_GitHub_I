## Per a què serveix una pull request?

Una pull request serveix per proposar que els canvis fets en una branca de treball s'incorporin a una altra branca, normalment main. També permet que altres persones revisin el codi, facin comentaris i comprovin que tot funciona correctament abans de fusionar els canvis.

## Base i compare

En una pull request des d'una branca de treball cap a main:

base: main (la branca on es volen afegir els canvis)
compare: la branca de treball (la branca que conté els canvis realitzats)

## Abans de crear-la

Fes una llista breu del que comprovaries abans d'enviar la pull request.

 - Tots els canvis estan desats i enviats (push) al repositori.
 - El projecte funciona correctament i no té errors.
 - He revisat els fitxers modificats i els comentaris de commit són clars.
